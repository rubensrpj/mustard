Approval-report fields that echo a marker must be NAMED for the marker (`markerVia`), not for the run — a field named `approvedVia` holding an earlier session's provenance is a silent wrong answer to "who approved this"; and `unknown == unknown` between two session ids is two absences, never an attribution.
