# Guias locais de desenvolvimento

As versões revisadas ficam aqui para revisão e integração por Git. São receitas de desenvolvimento do próprio Mustard, não templates instalados em todos os projetos. Na cópia de implementação, elas também foram colocadas em `apps/rt/.claude/skills`; os originais da branch/instalação em uso não foram alterados. Ao adotar a branch, copie cada `SKILL.md` para a pasta local de mesmo nome se quiser atualizar essas receitas particulares.

As fontes de autoridade continuam sendo registro, enums, CLI, código e provas vigentes. Os guias evitam exemplos extensos que envelhecem e não substituem leitura do contrato afetado.
