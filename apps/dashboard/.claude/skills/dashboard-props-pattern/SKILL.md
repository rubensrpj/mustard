## Purpose
`AcBreakdown/index.tsx`, `BaseRow/index.tsx` and `CodeBlock/index.tsx` are the canonical `components/page` leaf shape: one component per directory, its `<Name>Props` interface exported right above the component function it types. The interface is the component's entire public contract — nothing about internal helper functions (`resolveLanguage`, `DOT` lookup tables) leaks into it, and every one of the three components is a plain function component with no class, no `forwardRef`, no default export.

## Convention
Folder: apps/dashboard/src/components/page/**, apps/dashboard/src/features/economy/**, apps/dashboard/src/features/telemetry/PhaseStation/**, apps/dashboard/src/features/telemetry/PipelineTimeline/**, apps/dashboard/src/features/workspace/** · Extension: .tsx · Files of this role in this subproject: 37
Every exemplar names the interface `export interface <ComponentName>Props` and always includes an optional `className?: string` last, threaded via `cn()` into the component's root element so callers can compose Tailwind from outside. Optional visual/behavioural props get inline defaults in the destructured parameter list (`chevron = false`, `lang = "plain"`, `showLineNumbers = false`) rather than `defaultProps`. When a prop is itself a bounded vocabulary (`BaseRowProps.status`), the union is declared as a co-located `export type RowStatus = "a" | "b" | ...` immediately above the Props interface, not inlined into the prop type. JSDoc above the interface (or above the component) explains WHEN/WHY a component renders its various states (e.g. AcBreakdown's all-zero em-dash case).

## How to apply
A new presentational component gets its own `src/components/page/<ComponentName>/index.tsx` (or the matching `features/<domain>/...` leaf), exporting `<ComponentName>Props` immediately before `export function ComponentName(props: <ComponentName>Props)`. Destructure props with inline defaults for optional visual knobs, end the prop list with `className?: string`, and merge it via `cn(...)` on the root element rather than overriding it.
